# 🏗️ Архітектурний Blueprint: High-Performance Catalog & LeadGen Engine

Цей документ описує еталонну архітектуру, технологічний стек, структуру коду та інженерні принципи, застосовані в проєкті. Ви можете використовувати цей шаблон для створення будь-яких B2C або B2B каталогів, e-commerce систем, вітрин продукції чи сервісів лідогенерації (нерухомість, агротрейдинг, техніка, оптова торгівля).

| Компонент | Технологія | Призначення та переваги |
| :--- | :--- | :--- |
| **Build Engine** | **Vite (Rollup)** | Миттєвий HMR (< 50ms), мініфікація коду, збірка production-бандла за ~2 сек. |

| **Стилі & Теми** | **Scoped CSS + CSS Vars** | 0 зайвих runtime-бібліотек, миттєве завантаження, змінні кольорів у `:root`. |

| **Lead Pipeline** | **Telegram Bot API** | Миттєва доставка заявок (0.3 сек) у месенджер менеджерам без потреби у важких CRM. |
| **Деплой & CI/CD** | **GitHub ➔ Railway** | Автоматична збірка при `git push origin main`, нульовий час простою (Zero Downtime). |

## 2. 🧱 Ключові інженерні рішення та патерни

### А. Client-Side In-Memory Data Layer (0 мс затримки)
* **Концепція**: База даних об'єктів або товарів зберігається у структурованому форматі (`src/data/propertiesData.js`).
* **Чому це ефективно**:
  1. Будь-яка комбінація фільтрів (ціна, райони, характеристики, пошуковий текст) фільтрує сотні записів за **< 1 мілісекунду** на клієнті.
  2. Відсутність навантаження на серверні бази даних при пікових навантаженнях або парсингу.
  3. Карта (`Leaflet`) та сітка каталогу працюють від **єдиного джерела істини** (`filteredProperties`).

### Б. Anti-CORS Media Streamer (Безпечна роздача фото)
* **Проблема**: Завантаження зображень напряму зі сторонніх сайтів/CDN часто блокується політиками `CORS` або `Referer`.
* **Рішення**: Серверний маршрут `/api/media/:encodedUrl`, який:
  * Завантажує оригінальне зображення з імітацією заголовків браузера.
  * Кешує результат у пам'яті / на рівні HTTP Cache-Control.
  * Повертає клієнту чистий бінарний потік фотографії.

### В. Smart Booking & Direct-to-Telegram Form
* **Інтерфейс лідогенерації**:
  * Швидкі пресети дати: *«Сьогодні»*, *«Завтра»*, *«Інша дата»* (нативний календар).
  * Швидкі слоти часу: *«10:00 — 13:00»*, *«13:00 — 17:00»*, *«17:00 — 20:00»* + вибір точного часу.
  * Валідація українського формату телефону (`+380...`).
* **Форматування ліда**: відправка структурованого повідомлення в Telegram із клікабельним номером для дзвінка менеджера в 1 тап (`tel:+380...`) та посиланням на об'єкт.

### Г. Статусна система об'єктів (Active / Rented / Sold)
* Замість видалення товару, який тимчасово або остаточно зданий/проданий, йому присвоюється прапорець `isRented: true`.
* **Візуальний ефект**:
  * Картка напівпрозоро затемнюється стильним графітовим оверлеєм із легким блюром.
  * Поверх фотографії накладається тонкий діагональний штрих від кута до кута.
  * По центру виводиться чіткий білий напис **«ЗДАНО»** з преміальним трекінгом (`letter-spacing: 0.28em`).
  * Зберігається SEO-індексація та живе портфоліо компанії.

## 3. 📂 Еталонна структура файлів

```text
├── public/                     # Статика, favicon, robots.txt, sitemap.xml
├── server.js                   # Express Backend (Telegram API, Media Proxy, SPA route)
├── src/
│   ├── components/             # Модульні UI компоненти
│   │   ├── Navbar.jsx          # Шапка з контактами, швидким пошуком, валютами
│   │   ├── Hero.jsx            # Головний промо-блок з інтегрованим фільтром
│   │   ├── FilterBar.jsx       # Панель вибору категорій, цінових діапазонів, сортування
│   │   ├── PropertyCard.jsx    # Картка об'єкта (слайдер фото, бейджі, статус ЗДАНО)
│   │   ├── PropertyModal.jsx   # Детальна картка: лайтбокс, характеристики, лід-форма
│   │   ├── InteractiveMap.jsx  # Інтерактивна карта Leaflet із кастомними пінами
│   │   ├── ServicesModal.jsx   # Додаткові послуги компанії
│   │   └── Footer.jsx          # Підвал із реквізитами та юридичними даними
│   ├── data/
│   │   └── propertiesData.js   # Головний датасет об'єктів / товарів
│   ├── utils/                  # Утиліти: форматування цін (UAH/USD), дат, валідатори
│   ├── App.jsx                 # Головний контролер стану додатку та фільтрації
│   ├── main.jsx                # Вхідна точка React DOM
│   └── index.css               # Дизайн-токени (:root CSS), анімації, базові стилі
├── package.json
└── vite.config.js
```
